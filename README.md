# تحدي 96 ثانية — جودة الأداء، وفاء للوطن

موقع تفاعلي عمودي مخصص لشاشة لمس/Kiosk.

## ما يعمل الآن
- 5 مواقف من العرض.
- مؤقت 96 ثانية.
- نتيجة نهائية: مؤشر من 96 + بصمة في الجودة.
- عداد المشاركات حتى هدف 96.
- حفظ تلقائي للنتائج في IndexedDB + نسخة احتياطية LocalStorage.
- Full Screen من زر «ابدأ التحدي» أو F11.
- لوحة مشرف مخفية: اضغط رقم 96 أسفل الشاشة 5 مرات بسرعة، أو افتح `?admin=1`.
- تصدير CSV وتصفير النتائج.
- يتم تحميل أحدث نسخة منشورة تلقائيًا على شاشات الفعالية.

## المسارات

- `/play` شاشة اللمس والمشاركة (والصفحة الرئيسية `/` تفتح التجربة نفسها للتوافق).
- `/display` شاشة العرض اللحظي أمام الحضور.

## إعداد Supabase

1. أنشئ مشروع Supabase ثم افتح **SQL Editor**.
2. الصق وشغّل محتوى `supabase/setup.sql` كاملاً. ينشئ الجدول وRLS وRPC آمنة وترقيمًا متسلسلًا حتى 96، ويضيف الجدول إلى Realtime.
3. رابط المشروع ومفتاح النشر العام مهيآن في الواجهة الحالية. يمكنك اختياريًا نسخهما إلى `.env.local` لاستبدالهما دون تعديل الكود. لا تستخدم `service_role` إطلاقًا.
4. شغّل `npm install` ثم `npm run dev`. للإنتاج استخدم `npm run build`.

```env
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_ANON_KEY
```

تستخدم شاشة المشاركة RPC باسم `complete_participant` عند ظهور النتيجة فقط. تقفل الوظيفة المعاملة أثناء إعطاء رقم المشارك، لذلك لا يتكرر الرقم عند استخدام جهازين. تستخدم شاشة العرض Realtime كوسيلة أساسية وتزامنًا احتياطيًا كل 12 ثانية.

## Vercel

ارفع المستودع إلى Vercel كـ Vite project. يمكن إضافة متغيري البيئة أعلاه في Project Settings → Environment Variables عند الرغبة في استبدال الإعدادات العامة المهيأة. يضمن `vercel.json` فتح `/play` و`/display` مباشرة دون 404.

## الشاشة
التصميم Portrait ومناسب لـ 1080×1920. على جهاز Windows استخدم Edge أو Chrome واضغط «ابدأ التحدي» للسماح بالـ Full Screen. F11 بديل مضمون.

## حفظ البيانات
النسخة الحالية تحفظ كل المشاركات على نفس جهاز/متصفح الكشك حتى بعد الإغلاق وإعادة الفتح.

### النسخة المحلية الاحتياطية

يحفظ الجهاز المحاولة المعلقة محليًا عند انقطاع الشبكة ويحاول إرسالها عند عودة الاتصال. لا يظهر هذا الحفظ في العداد المركزي إلا بعد نجاح الإضافة إلى Supabase.

## الشعارات
الموقع يعرض الصور من المصادر الرسمية:
- وزارة الموارد البشرية والتنمية الاجتماعية: `hrsd.gov.sa`
- اليوم الوطني السعودي 96: `cdn.gea.gov.sa`

## ملاحظة عن احتساب النتيجة
كل خيار يحمل وزن 1 أو 2 أو 3. المؤشر = مجموع الأوزان ÷ الحد الأعلى × 96. البصمة تختار أقوى بعد ظهر في الإجابات، وعند التعادل يُستخدم زمن الاستجابة لحسمها.
